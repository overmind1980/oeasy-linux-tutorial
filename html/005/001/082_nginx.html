方法

上手

  • 先更新
    • sudo apt update
  • 再安装
    • sudo apt install nginx

启动

  • nginx -s signal
  • 其中signal可以是
    • stop
    • reload
    • 等等

  • 这并不是标准的服务启动方法

具体启动

  • 服务有一些比较简单的启动和停止的方法
  • /etc/init.d/nginx start
  • /etc/init.d/nginx stop

  • 因为nginx要写错误日志
    • 如果没有建立文件夹的权限
    • 就需要使用管理员权限运行nginx

  • 怎么确认nginx已经启动器来了呢？
    • 先关闭nginx
    • sudo nginx stop

尝试

  • 先确认localhost目前没有响应
    • 关闭火狐浏览器

  • 运行
    • sudo service nginx start
    • firefox http://localhost
    • 地址栏里面输入http://localhost
      • 注意http没有s

已经运行

  • 如果nginx已经开始运行了
  • 会显示绑定到80端口失败
  • 想要重新运行的话需要先结束
  • 先要找到原来这个已经开始的进程

观察进程

  • ps aux | grep nginx

结束进程

  • sudo kill -9 pid
  • 就直接结束进程
  • 他有一个master
  • 4个worker
  • 或者把nginx的服务停止

解决

  • 在哪里配置呢？

  • 里面有个default文件

  • 好像是个规矩
  • apache也是这个位置
  • 我们在这里添加oeasy.html就好使了
