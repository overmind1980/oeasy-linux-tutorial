总结

  • tree是一个查询递归查询文件夹结构的命令
  • tree 有一些参数
    • 只遍历路径 -d
    • 控制路径层级 -L
    • 控制匹配模式 -P
      • 控制路径符合匹配模式 --matchdirs
      • 控制不显示空路径 --prune
    • 控制不匹配模式 -I
    • 遍历符号链接 -l
