复制目录

  • 直接赋值是略过目录的

  • 这应该查看一下手册中的参数

  • -r
    • 递归地复制文件夹和子文件夹

动手

  • 源路径、目标路径、参数都必须明确

  • 还有什么样的参数么？

更多参数

  • -d
    • 复制时保留链接
    • 链接相当于 Windows 系统中的快捷方式

  • -p
    • 除复制文件的内容外
    • 还把修改时间和访问权限也复制到新文件中

  • -a
    • 等价于-dR --preserve=all

覆盖提示

  • -f
    • 覆盖已经存在的目标文件而不给出提示
  • -i
    • 与 -f 选项相反
    • 在覆盖目标文件之前给出提示
    • 要求用户确认是否覆盖
    • 回答 y 时目标文件将被覆盖

链接文件

  • -l
    • 不复制文件
    • 只是生成链接文件
  • 什么是链接文件
  • 这个有点不懂了

总结

  • 这次我们学习了cp命令
  • cp有两个关键因素
    • 源
    • 目标
  • 源和目标都可以用绝对路径和可以用相对路径
    • 绝对路径
      • 清晰
      • 但一般比较长
    • 相对路径
      • 较短
      • 但头脑一定要清晰
  • cp 还有一些参数
    • -r 递归
    • -f 强制
    • -i 交互
    • -l 只生成链接
