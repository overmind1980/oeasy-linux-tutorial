牛说

  • 这次我们下载个牛说
    • cowsay：
sudo apt install cowsay
  • cowsay 牛说
    • cow 就是牛 🐄
    • say 就是说 🗣
  • cowsay 就是牛说
  • 牛说的东西作为参数给 cowsay
cowsay oeasy

  • 还有什么好玩的呢？👁
  • 我们查查手册！📕

表情

cowsay -p oeasy
cowsay -s oeasy
cowsay -e *- oeasy

更多表情

  • -b 极简主义 Borg Mode
  • -d 死亡状态 dead
  • -g 贪婪金钱 greedy
  • -p 偏执狂 paranoia
  • -s 石化 stone
  • -w 紧张睁大眼 wired
  • -t 闭眼的
  • -e 设置眼睛 eye 字符 后面眼睛字符
