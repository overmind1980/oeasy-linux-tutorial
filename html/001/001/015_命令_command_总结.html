命令 Command🧐

  • 命令分两种

  • 一种是在硬盘上的

    • 可以用apt 找到源码和帮助
    • 比如
      • uname
      • ls
      • cat
      • pwd
      • 灵魂三问
      • whatis
      • whereis
      • which
      • man
      • clear

  • 另一种是在系统内置(builtin)的

    • 可以在shell的源代码中找到实现过程
    • 比如
      • cd
      • pwd ‘

  • 还有一个比较特殊

    • 特别有权限的sudo

命令行快捷方式 💡

  • 记忆命令
  • ⬆️ 上一条命令
  • ⬇️️ 下一条命令
  • ctrl+r 搜索历史命令
  • 快速移动
  • ⬅️ 向左一格
  • ➡️️ 向右一格
  • ctrl+⬅️ 向左一个单词
  • ctrl+➡ 向右一个单词
  • ctrl+a 直接到头ahead
  • ctrl+e 直接到尾end
  • 快捷键清屏
  • ctrl+l清屏
  • 快速删除
  • ctrl+c 忽略当前行
  • ctrl+u 从光标位置开始，删除左方所有的字符，直到该行开始的位置
  • ctrl+k 从光标位置开始，删除右方所有的字符，直到该行结束的位置
  • 登出系统
  • ctrl+d 快快退出终端
  • ctrl+w 向前删除到词头
  • 急急如律令
  • 可以打印到一个鼠标垫上
